# REFORM iPad demo

The app is packaged as an installable Progressive Web App (PWA), because iPadOS cannot run Windows `.exe` files.

## Share it

1. Upload the contents of `REFORM-iPad-Demo.zip` to any static HTTPS host (for example Netlify Drop, Cloudflare Pages, GitHub Pages, or your own server).
2. Send the resulting HTTPS link to the person demonstrating the app.
3. On the iPad, open the link in Safari.
4. Tap **Share** → **Add to Home Screen** → **Add**.

After the first successful load, the installed app caches its files for offline use. Assessment records remain in that iPad browser's local storage and are not uploaded by this app.
